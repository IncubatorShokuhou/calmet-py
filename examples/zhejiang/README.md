# Zhejiang end-to-end example

This example runs all five PyCALMET stages from source datasets and traditional
control files. It does not use a prepared geophysical grid.

## Bundled inputs

- Three WRF records for 2018-03-18 00:00, 01:00, and 02:00 UTC. The last
  record is the following-hour boundary needed for a 00:00–01:00 CALMET run.
- 42 original SRTM3 tiles under `terrain/srtm3/`, covering N26–N31 and
  E117–E123. Each `.hgt` file is a 1201 × 1201 signed 16-bit elevation grid.
- `landuse/zhejiang_generic.landuse`, a WGS-84 categorical point dataset with
  one source record at each target-grid cell center. Its categories preserve
  the validated Zhejiang example's dominant land use using the corresponding
  USGS classes.
- One control file per stage under `config/`. Their relative input and output
  paths form a complete processing chain.

Verify the source files from the repository root:

```bash
sha256sum -c examples/zhejiang/SHA256SUMS
cd terrain/srtm3 && sha256sum -c SHA256SUMS && cd ../..
```

## Run

Install the package and execute the example from the repository root:

```bash
python -m pip install -e .
./examples/zhejiang/run.sh
```

The runner makes these calls without duplicating parameters from the control
files:

```python
pycalmet.calwrf("examples/zhejiang/config/calwrf.inp")
pycalmet.terrel("examples/zhejiang/config/terrel.inp")
pycalmet.ctrproc("examples/zhejiang/config/ctgproc.inp")
pycalmet.makegeo("examples/zhejiang/config/makegeo.inp")
pycalmet.calmet("examples/zhejiang/config/calmet.inp")
```

Products are written under `output/zhejiang/`:

```text
calwrf.nc       canonical CALWRF output
terrain.nc      terrain rebuilt from the 42 SRTM3 tiles
landuse.nc      land-use fractions generated by CTGPROC
geo.nc          geophysical grid generated by MAKEGEO
calmet.nc       final one-hour CALMET result
```

The complete run writes about 190 MB. CALWRF passes its canonical NetCDF file
directly to CALMET, so the example does not create an M3D intermediate. The WRF
subsets retain every variable read by CALWRF and use lossless NetCDF4
compression.
